Detailed Description

template<class Context, class Tag>
class cookmem::TLSContextScope< Context, Tag >

Temporarily provides a function-scope context to default-constructed allocators using the matching TLSContextProvider.

Declare the scope before containers that use the context so those containers are destroyed before the context.
