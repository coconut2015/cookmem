Detailed Description

template<class Arena = MmapArena, class Logger = NoActionMemLogger, class TreeType = PtrRBTree, class T = void>
class cookmem::CachedMemContext< Arena, Logger, TreeType, T >

A cached memory context that creates a MemPool using self-contained arena and logger.

This class is mostly used in cases when arena or logger both have default constructors.

Create a new, empty memory context with the same padding size as another context. No memory is copied, and the new context has its own logger.

Parameters
otherthe other memory context.
shareArenatrue to share the cached arena of the other context, so that segments released by either context can be reused by the other. false to use the cached arena of the new context.
