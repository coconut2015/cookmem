Detailed Description

template<class Arena = MmapArena, class Logger = NoActionMemLogger, class TreeType = PtrRBTree, class T = void>
class cookmem::SimpleMemContext< Arena, Logger, TreeType, T >

A basic memory context that creates a MemPool using self-contained arena and logger.

This class is mostly used in cases when arena or logger both have default constructors.
