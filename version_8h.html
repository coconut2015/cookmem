Detailed Description

The version of CookMem.

This is the only place where the version number is defined. CMakeLists.txt reads COOKMEM_VERSION_MAJOR, COOKMEM_VERSION_MINOR and COOKMEM_VERSION_PATCH from this file, so keep each of them on its own line in the form "#define COOKMEM_VERSION_XXX number".

◆ COOKMEM_VERSION

#define COOKMEM_VERSION    (COOKMEM_VERSION_MAJOR * 10000 + COOKMEM_VERSION_MINOR * 100 + COOKMEM_VERSION_PATCH)

The version as a single number, MAJOR * 10000 + MINOR * 100 + PATCH, so that it can be compared in preprocessor conditions. For example, version 1.2.3 is 10203.

#if COOKMEM_VERSION >= 10000
// code that requires CookMem 1.0 or later
#endif
