Detailed Description

template<class T, class ContextProvider = MemContextProvider<CachedMemContext<> >>
class cookmem::Allocator< T, ContextProvider >

An STL allocator that allocates through its context provider.

Allocator copies and rebound allocators retain the same provider.

T must not require an alignment larger than ALLOCATION_ALIGNMENT. Using such a type causes a compile error when memory is allocated.
