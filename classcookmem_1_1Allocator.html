Detailed Description

template<class T, class Arena = MmapArena, class Logger = NoActionMemLogger, class TreeType = PtrRBTree>
class cookmem::Allocator< T, Arena, Logger, TreeType >

An allocator backed by a caller-owned CookMem memory context.

Allocator copies and rebound allocators share the same context.
