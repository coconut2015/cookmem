◆ ALLOCATION_ALIGNMENT

const std::size_t cookmem::ALLOCATION_ALIGNMENT = sizeof (std::size_t) * 2

The alignment of every pointer returned by allocate () of a memory context: twice the size of std::size_t, which is 16 bytes on 64-bit platforms and 8 bytes on 32-bit platforms. Use allocateAligned () for a larger alignment.

◆ DEFAULT_IMMEDIATE_RELEASE_THRESHOLD
