Detailed Description

template<class Arena, class Logger, class TreeType = PtrRBTree, class T = void>
class cookmem::MemPool< Arena, Logger, TreeType, T >

A memory allocator.

Note that this class only provides the algorithm necessary to deal with small memory chunks. The actual ability to get memory segment (such as mmap memory pages) is deferred to memory arena.

Call a visitor function for every allocation that has not been freed, like inspect_all in dlmalloc. This can be used to find memory leaks.

◆ setImmediateReleaseThreshold()

template<class Arena, class Logger, class TreeType = PtrRBTree, class T = void>
void cookmem::MemPool< Arena, Logger, TreeType, T >::setImmediateReleaseThreshold ( size_type threshold)
inline

Set the size at which freed allocations release their memory right away.

A large allocation usually gets a segment of its own. When an allocation at least this large is freed and its segment becomes entirely free, the segment is released to the arena immediately, instead of at the next empty-segment trimming pass. This is similar to the mmap threshold of dlmalloc.

Parameters
thresholdthe allocation size in bytes. The default is DEFAULT_IMMEDIATE_RELEASE_THRESHOLD. 0 disables the immediate release.

◆ setTrimEmptySegmentsInterval()

template<class Arena, class Logger, class TreeType = PtrRBTree, class T = void>
void cookmem::MemPool< Arena, Logger, TreeType, T >::setTrimEmptySegmentsInterval ( size_type interval)
inline

Set the number of deallocations between empty-segment trimming passes.

Memory segments that become entirely free are kept for later allocations. After every interval deallocations, the segments that are entirely free are released to the arena. A smaller interval keeps the footprint smaller, but releases and obtains segments more often.

Parameters
intervalthe number of deallocations between the passes. The default is DEFAULT_TRIM_EMPTY_SEGMENTS_INTERVAL. 1 (or 0) releases empty segments on every deallocation.
