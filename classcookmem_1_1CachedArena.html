Detailed Description

template<class Arena, class TreeType = PtrRBTree>
class cookmem::CachedArena< Arena, TreeType >

CachedArena is used to cache the segments released and see if they can be reused in the future segment request.

This class implements the interface of MemArena without explicitly inheriting from it. This is to avoid the overhead of virtual function calls and allows inlining of the functions.

Template Parameters
Arenathe memory arena that does the actual memory allocation
TreeTypeThe type of the tree used to cache the released segments. The default is PtrRBTree.
