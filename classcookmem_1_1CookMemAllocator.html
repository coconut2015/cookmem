Detailed Description

template<class T, class Arena = MmapArena, class Logger = NoActionMemLogger, class TreeType = PtrRBTree>
class cookmem::CookMemAllocator< T, Arena, Logger, TreeType >

An allocator backed by its own CookMem memory context.

Allocator copies and rebound allocators have independent contexts.
