Detailed Description

template<class Context>
class cookmem::MemResource< Context >

A std::pmr::memory_resource that allocates from a memory context, so that the std::pmr containers can use it. It needs C++17, and is available when COOKMEM_HAS_PMR is 1.

Alignments larger than the allocation alignment use allocateAligned (). When the context cannot allocate the memory, std::bad_alloc is thrown, as std::pmr::memory_resource requires.

Template Parameters
Contexta memory context, such as cookmem::MemContext or cookmem::SimpleMemContext, with void as the value type.
