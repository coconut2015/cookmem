Detailed Description

The node of RedBlackTree, which is stored in the memory being tracked.

The memory pool places this node at the start of a free chunk, so its layout must match the chunk header: the second word (m_size) is both the value of the node and the size field of the chunk. The memory must be at least sizeof(PtrRBNode) (7 words) large.

Nodes with the same value are kept in a doubly linked list (DLL) attached to the one node that is in the tree.
