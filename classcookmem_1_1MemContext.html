Detailed Description

template<class Arena, class Logger, class TreeType = PtrRBTree, class T = void>
class cookmem::MemContext< Arena, Logger, TreeType, T >

A basic memory context that creates a MemPool based on the arena and logger references user passed in.

This class is mostly used in cases when arena or logger that do not have default constructors.

inline

Release all the memory segments held by this MemPool, then the segments cached by the arena, so that the memory is returned to the system. Every pointer allocated from this context becomes invalid.

Unlike releaseAll (), this also empties the cache of a CachedArena, including the segments that other contexts sharing the arena could have reused.

◆ setTrimEmptySegmentsInterval()

template<class Arena , class Logger , class TreeType = PtrRBTree, class T = void>
void cookmem::MemContext< Arena, Logger, TreeType, T >::setTrimEmptySegmentsInterval ( size_type  interval)
inline

Set the number of deallocations between empty-segment trimming passes.

Memory segments that become entirely free are kept for later allocations. After every interval deallocations, the segments that are entirely free are released to the arena. A smaller interval keeps the footprint smaller, but releases and obtains segments more often.

Parameters
intervalthe number of deallocations between the passes. The default is DEFAULT_TRIM_EMPTY_SEGMENTS_INTERVAL. 1 (or 0) releases empty segments on every deallocation.
