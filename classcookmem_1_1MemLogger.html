Detailed Description

A MemLogger logs memory allocation, deallocation, and errors.

This class here is merely used to define the functions needed to implement a MemLogger.

int  line = __LINE__ 
)
pure virtual

Log an error that the memory pool detected: a double free (MEM_ERROR_DOUBLE_FREE), overwritten padding bytes (MEM_ERROR_PADDING), or an invalid padding size when the pool is created (MEM_ERROR_GENERAL). The loggers of CookMem throw Exception with the same error, message, file and line. A logger may record the error first, or throw its own exception. It is not safe to go on after an error, so if this function returns, the pool throws Exception itself.

Parameters
userPtrthe user pointer that had the error, or nullptr.
errorthe type of the error encountered.
messagea description of the error.
filethe source file where the error was detected.
linethe line number where the error was detected.
